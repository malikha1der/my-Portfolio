# Malik Haider — 3D Interactive Portfolio

A modern, high-performance 3D interactive developer portfolio designed and built from scratch using React, TypeScript, Three.js, and Tailwind CSS. Features real-time particle fields, dynamic interactive 3D geometry with custom wireframe shaders, smooth section navigation, and responsive design across all devices.

---

## 🚀 Highlights & Features

- **Interactive 3D Stage**: Real-time Three.js scene featuring dynamic geometry, particles, mouse-reactive lighting, and performance-optimized canvas rendering.
- **Modern Tech Stack**: Built with React 19, TypeScript, Tailwind CSS v4, and Motion.
- **Responsive Layout**: Designed for seamless experience across mobile, tablet, and ultra-wide screens.
- **Interactive Skills Marquee**: Auto-scrolling infinite skills track with auto-snap to whole cards on pause and single-card step navigation.
- **Featured Projects Showcase**: Detailed project cards with live demo links, repository access, and technology badges.
- **Career Timeline & Education**: Interactive chronological journey detailing development experience.
- **Working Contact Form**: Clean form integrated with EmailJS for direct client and recruiter inquiries.

---

## 🛠️ Tech Stack

- **Frontend**: React 19, TypeScript
- **3D Graphics & Canvas**: Three.js
- **Animations**: Motion (`motion/react`)
- **Styling**: Tailwind CSS v4
- **Icons**: Lucide React
- **Build Tool**: Vite

## 📦 Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) (v18 or higher) installed on your machine.

### Installation

1. Clone or download the repository:
   ```bash
   git clone https://github.com/your-username/malik-haider-portfolio.git
   cd malik-haider-portfolio
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the local development server:
   ```bash
   npm run dev
   ```

4. Open your browser and navigate to:
   ```
   http://localhost:3000
   ```
